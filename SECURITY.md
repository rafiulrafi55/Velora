# Security Policy

## Reporting a Vulnerability

The security of this project is important. If you discover a security vulnerability, please report it responsibly so it can be investigated and fixed before it is publicly disclosed.

### How to Report

Please send a detailed report to:

**Email:** rafiulrafi55@gmail.com

Include the following information whenever possible:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or commit (if known).
- Proof-of-concept code, screenshots, or videos (if applicable).
- Any suggested mitigation or fix.

### What to Expect

- **Acknowledgement:** Within **48 hours** of receiving your report.
- **Status Updates:** At least **once every 7 days** while the issue is being investigated.
- **Resolution:** If the vulnerability is confirmed, a fix will be developed and released as soon as reasonably possible. You will be notified when the issue has been resolved.

### Responsible Disclosure

Please do **not** publicly disclose the vulnerability until a fix has been released or you have received permission to do so. Responsible disclosure helps protect users of this project.

### Scope

This policy applies to all code, documentation, and related assets maintained in this repository.

Thank you for helping keep this project and its users safe.
